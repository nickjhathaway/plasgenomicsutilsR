# Deprecated name for load_genotypes()

`run_ld_prune()` was renamed to
[`load_genotypes()`](https://nickjhathaway.github.io/plasgenomicsutilsR/reference/load_genotypes.md):
the old name reads oddly for what it mostly does, and reads as a
contradiction with `prune = FALSE`. Kept so existing scripts keep
working.

## Usage

``` r
run_ld_prune(...)
```

## Arguments

- ...:

  Passed to
  [`load_genotypes()`](https://nickjhathaway.github.io/plasgenomicsutilsR/reference/load_genotypes.md).

## Value

See
[`load_genotypes()`](https://nickjhathaway.github.io/plasgenomicsutilsR/reference/load_genotypes.md).
