# Pf3D7 drug-resistance / selection example genes

A small, curated subset of
[PF3D7_GENES](https://nickjhathaway.github.io/plasgenomicsutilsR/reference/PF3D7_GENES.md):
well-known *P. falciparum* drug-resistance and selection loci (`pfcrt`,
`pfdhfr`, `pfmdr1`, `pfdhps`, `pfkelch13`, `pfaat1`, `pfgch1`, `pfpx1`).
Used as the default `genes` track of
[`example_ibd_results()`](https://nickjhathaway.github.io/plasgenomicsutilsR/reference/example_ibd_results.md)
and throughout the documentation.

## Usage

``` r
PF_EXAMPLE_DRUG_GENES
```

## Format

A data frame with 8 rows and the same columns as
[PF3D7_GENES](https://nickjhathaway.github.io/plasgenomicsutilsR/reference/PF3D7_GENES.md).

## Source

VEuPathDB / PlasmoDB Pf3D7 GFF, release version 2020-09-01.
